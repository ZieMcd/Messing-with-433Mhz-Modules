# Messing-with-433Mhz-Modules

I wanted to control a keep remote control lamp light I bought off amazon, doing a bit of googling, it seemed like most of these cheap remotes work with 433Mhz transmitters and receivers. So I bought some modules to hook up to raspberry pi https://www.amazon.co.uk/dp/B07DJ2ZJXR?ref_=ppx_hzsearch_conn_dt_b_fed_asin_title_1

As it turns it out the lamps don't use 433 Mhz but instead 2.4 GHz.  
Anyway now I have some 433 Mhz modules. I've been wanting to mess around with lower level languages and understand more about linux stuff like file descriptors and maybe even how the kernal works. So I'm just going play around with modules as a way to learn more about theese things.
